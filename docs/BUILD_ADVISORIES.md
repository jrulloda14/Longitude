## Current decision and exposure controls

Retain the existing Tailwind 3 design contract in Milestone 2. Content globs and source/config files must be trusted. Development/test/preview servers bind to loopback; no application feature accepts build patterns, uploads source/config, or invokes Node glob tooling on user data. Browser tests use an isolated local build and installed Edge. These conditions reduce exposure but **do not fix the advisory** or make untrusted repositories/config safe to execute. A malicious build configuration is already executable code, so reviewing build inputs remains necessary independently of this DoS finding.

Do not run `npm audit fix --force` as an implicit design-system migration. Recheck for compatible fixes in later milestones/releases. A scoped patch/fork is possible but adds maintenance/security-review obligations; none was silently introduced here. No waiver of runtime/native security checks follows from this development-only exposure decision.

The earlier moderate selector-parser advisory was addressed in Milestone 1 by pinning `postcss-selector-parser 7.1.6`; that override remains. Runtime dependencies are unchanged in Milestone 2. Raw resolved evidence is in [full audit](evidence/milestone-2/npm-audit-all.json) and [production-only audit](evidence/milestone-2/npm-audit-production.json). The dependency review and lockfile record exact versions/licenses; audit output is advisory-database evidence, not proof against undisclosed defects.
