# Security policy

Longitude runs entirely on your computer. It has no servers or accounts and makes no network requests. Its native permissions are limited to its own settings file, writing text to the clipboard and saving a calendar file you choose.

## Supported versions

Security fixes go into the latest release.

## Reporting a vulnerability

Please **don't open a public issue**. Instead, use GitHub's private reporting: open the repository's **Security** tab and choose **Report a vulnerability**. Include the steps to reproduce, the affected version and platform, and the impact you see.

You'll get an acknowledgement as soon as possible. Fixes are released with a note in the [changelog](CHANGELOG.md).
